# Impara · Lotto 14

Three photo-grounded review proposals after batch 13: incorporating poolish into the final dough, working the dough after autolyse, and supporting a stretched pizza base on the backs of the hands. These clarify specific gestures in Prefermenti and Problemi e soluzioni; they do not fill the already illustrated glossary with decorative duplicates.

Not integrated into the application or published. Review in `review.html`; project WebPs in `assets/`; exact prompts and input-image roles in `prompts.json`. Mode: built-in Imagegen, one distinct call per asset. All original PNG masters and photographic research are preserved in `/Users/matteo/dev/Vulcan/output/learn-illustration-batch-14-2026-11-01/`.

The approved bench-fold illustration establishes style only. Photographs establish the material consistency, pose and physical contacts. The poolish reference is an actual poolish transfer by Eva / Electric Blue Food. Rebecca Eisenberg / The Practical Kitchen supplies the actual post-autolyse pinch-through gesture and hand-back stretching pose. Source photos are not distributed with the gallery or application. Photographic inspiration stays internal, as requested by Matteo; public captions explain only the action.

The post-autolyse reference recipe includes sugar in its yeast mixture. The illustration borrows only the mixing gesture and does not add sugar to Vulcan’s method. It does not prescribe quantities, timings or a universal order of incorporation. The stretching scene is an observed pose with the hands supporting dough; it is not a toss, a windowpane test or a measurement of thickness.

Exports use Pillow only for resizing, format conversion and contact sheets, preserving generated alpha. Run `python3 design-assets/learn-illustrations-batch-14/build.py` with the original masters present to rebuild. Old application artwork remains unchanged.
